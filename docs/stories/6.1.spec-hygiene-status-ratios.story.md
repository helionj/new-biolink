**WCAG 2.1 ratio calc algorithm (referência verbatim):**

```
ratio = (L1 + 0.05) / (L2 + 0.05)
where L1 = max(luminance_a, luminance_b), L2 = min(luminance_a, luminance_b)
luminance(R, G, B) = 0.2126 * R_linear + 0.7152 * G_linear + 0.0722 * B_linear
R_linear = (R_sRGB <= 0.03928) ? R_sRGB/12.92 : ((R_sRGB + 0.055)/1.055)^2.4
(R_sRGB = R_int / 255)
```

**Thresholds AA 2.1 (relevantes para Story 6.1):**

- Normal text 4.5:1 (`§1.4.3`)
- Large text 3:1 (`§1.4.3`; ≥18px regular ou ≥14px bold)
